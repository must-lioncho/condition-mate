# goal-57: 대시보드 짧은 라벨이 줄바꿈/오버플로우되는 UI 렌더링 깨짐 수정

## 상태
backlog

## 목적
ConditionManager 대시보드에서 짧은 라벨들이 폰트 크기·컬럼 폭 문제로 2줄 이상으로 줄바꿈되거나 박스를 넘쳐 렌더링이 깨지는 문제를 해결한다. 1400px 폭 실측 기준으로 발견되었으며, 짧은 라벨이 한 줄에 들어가지 않으면 시각적으로 깨져 보인다.

## 작성일
2026-06-25

## 1. 증상
약 1400px 뷰포트 폭에서 다음 요소들이 2줄 이상으로 줄바꿈되거나 박스를 넘침:

- `td` "대시보드 UI 렌더링 깨짐 탐지 · goal 문서 자동 생성" — 2줄로 줄바꿈 (w=210)
- `button` "즉시 실행" — 짧은 버튼 라벨이 2줄로 줄바꿈 (w=70)
- `th` "마지막 실행" — 테이블 헤더가 2줄로 줄바꿈 (w=54)

## 2. 수용 기준

- `td` "대시보드 UI 렌더링 깨짐 탐지 · goal 문서 자동 생성"이 일반적인 컬럼 폭에서 박스 안에 한 줄로 렌더링된다.
- `button` "즉시 실행" 라벨이 한 줄로 렌더링되며 버튼 박스를 넘치지 않는다.
- `th` "마지막 실행" 헤더가 한 줄로 렌더링된다.
- 위 요소들이 흔히 쓰이는 뷰포트 폭(예: 1400px 포함)에서 줄바꿈·오버플로우 없이 표시된다.
