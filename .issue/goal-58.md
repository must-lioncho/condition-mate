# goal-58: 일정관리 뷰에서 '완료된 부모 목표'가 완료로 안 걸러지고 미완료(지남/미정)로 표시되는 상태 불일치

- 상태: backlog
- 목적: 상태 필터는 부모를 '완료'로 취급해 거르는데, 같은 일정관리 화면의 그룹 분류·D-day 배지는 부모를 '미완료'로 취급한다. 그래서 모든 자식이 완료된 부모 목표가 완료 그룹이 아니라 '지남(기한 초과)'에 빨간 D+N 배지로 계속 떠, 끝난 일이 미해결 업무처럼 보인다. 한 화면 안에서 '완료' 판정이 서로 어긋나는 버그.
- 작성일: 2026-06-25
- 관련 코드: Sources/ConditionManager/Dashboard/DashboardContent.swift:1694 (일정관리 버킷 분류), :1657 (ddayBadge), :1142 (effStatus), :1361-1366 (derivedStatus), :1177-1184 (goalPasses 필터), :1593-1594 (그룹뷰 완료 태그)

## 1. 증상 / 재현

재현 절차:
1. 최상위(부모) 목표 P를 하나 만들고, P의 **목표(target) 날짜**를 어제(과거)로 지정한다. (P 자신의 상태는 수동으로 건드리지 않음 — 부모는 롤업 상태를 쓴다.)
2. P 아래에 자식 태스크 1~2개를 추가하고, 그 자식들을 **전부 '완료(done)'** 로 바꾼다.
3. 상단 상태 필터는 기본값(완료 ON) 그대로 둔 채, **일정관리(schedule)** 뷰를 연다.

기대 동작:
- P는 모든 자식이 완료됐으므로 derivedStatus가 'done'이다. 그룹(group) 뷰에서는 실제로 P에 초록색 "완료" 태그가 붙는다(:1593-1594). 일정관리 뷰에서도 P는 맨 아래 **"완료"** 섹션에 들어가고 완료 배지(✓)가 붙어야 한다.

실제 동작:
- 일정관리 뷰에서 P는 **"지남 (기한 초과)"** 섹션에 들어가고, **빨간 "D+N 지남"** 배지가 달린다. 즉 모든 작업이 끝난 부모 목표가 '기한 초과된 미해결 업무'처럼 표시된다. (목표 날짜가 없으면 "미정" 섹션으로 빠지며, 역시 완료로 분류되지 않는다.)
- 결정적 모순: 같은 화면의 상태 필터에서 **'완료' 토글을 끄면 P가 사라진다** — 필터는 P를 '완료'로 보고 거르기 때문이다(goalPasses → effStatus='done'). 그런데 '완료' 토글을 켜 둔 상태의 분류/배지는 P를 '완료'가 아니라고 본다. 한 목표가 "완료 필터로는 가려질 만큼 완료" 이면서 동시에 "완료 그룹·배지에는 못 들어갈 만큼 미완료" 인, 명백히 어긋난 판정이다.

## 2. 원인 분석

상태 판정에 두 가지 서로 다른 기준이 섞여 있다.

- 필터 경로는 **롤업 기준** `effStatus`를 쓴다. `effStatus`(:1142)는 부모면 `derivedStatus`(:1361-1366)를 반환하고, derivedStatus는 "자식이 모두 done이면 'done'"을 돌려준다. 따라서 `goalPasses`(:1177-1184)의 `return !!_statusFilter[effStatus(g,goals)]`는 자식이 전부 완료된 부모를 'done'으로 취급한다 → 완료 필터를 끄면 숨겨진다.

- 반면 일정관리 뷰의 분류/배지는 부모의 **원본 필드** `g.status`만 본다:
  - 버킷 분류 :1694 `if((g.status||'backlog')==='done'){ G.done.push(g); return; }`
  - D-day 배지 :1657 `if((g.status||'backlog')==='done'){ ... 완료 배지 ... }`
  부모 목표는 수동 상태를 갖지 않으므로 `g.status`는 보통 'backlog'(미설정 기본값)이다. 그래서 두 분기 모두 false가 되어, 자식이 전부 완료됐어도 P는 완료 그룹/완료 배지로 가지 못하고 `targetAt` 기준 일반 버킷(과거면 G.over='지남')으로 떨어지며 D+N 빨간 배지를 받는다.

즉 :1694, :1657은 `derivedStatus`/`effStatus`(롤업)를 써야 할 자리에 raw `g.status`를 써서, 그룹 뷰(:1593-1594)·상태 필터(:1182)와 완료 판정이 불일치한다.

## 3. 수용 기준

- 모든 자식이 '완료'인 부모 목표 P(자신의 status는 미설정)가, 일정관리 뷰에서 "완료" 섹션에 들어가고 완료(✓) 배지를 받는다. "지남/미정" 등 미완료 버킷이나 빨간 "D+N 지남" 배지로 표시되지 않는다.
- 그룹 뷰의 "완료" 태그, 상태 필터의 '완료' 가시성, 일정관리 뷰의 완료 분류·배지가 같은 부모 목표에 대해 항상 동일한 결론(모두 완료 또는 모두 미완료)을 낸다.
- 회귀 방지: 자식 중 하나라도 미완료(또는 진행 중)인 부모는 일정관리에서 완료 섹션으로 가지 않고 기존대로 target 기준 버킷/배지를 유지한다. 자식이 없는 단일(leaf) 목표의 기존 분류 동작은 바뀌지 않는다.
