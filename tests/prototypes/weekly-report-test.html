상세는 주신 "베스트" 포맷 그대로 — 부서 = 접이식, 부모(브랜드) = 하위 그룹. 기본은 헤더+카운트만, 클릭해야 펼쳐짐.
각 항목 앞 Diff 뱃지 + 뒤 마감일. 팀 규칙대로 빨강/녹색 신호등 배제 — 대기=보라, 강조는 앰버로.
③ 어뷰징 방지 (복붙을 "막는" 게 아니라 "드러냄")
신규 주간 Diff
지난주 스냅샷과 비교해 새 항목·변경분만 표시. 복붙하면 강조가 하나도 없어 즉시 티남.
3주째 정체 태그
문구가 지난주와 같으면 "N주째 동일" 자동 부착 + 카톡 요약에도 노출. 반복이 스스로 고발됨.
지연 마감일 채색
항목마다 목표일. 지났는데 미완이면 앰버 강조. "곧 완료" 무한반복 차단.
대기 상태 뱃지 강제
신규/진행/완료/지연/대기 중 필수 선택. 뭉개는 서술 불가. 대기=보라(팀 규칙).
핵심 두 개는 주간 Diff + 정체 태그. 이 둘만으로 "이번 주 움직인 것"과 "말만 반복"이 자동 분리됨. 정체 건수는 카톡 텍스트에도 한 줄로 올라감.
④ 앱 연동 메모 (구현 시)
상세 페이지는 새 문서가 아니라 지금 대시보드가 곧 리포트가 되게 함:
· 부서 = goal 트리, 부모(브랜드) = 트리 1단계 하위 (goal-link-context-model 그대로)
· 항목 = goal/task, 상태·마감일은 기존 필드 재사용 · 새 필드는 reviewJSON() 수기 직렬화 + lastView 허용목록 등록 필요
· Diff = 매주 월요일 주간 스냅샷 한 장 떠두고 다음 주 텍스트 비교 → 신규/변경/동일 판정
· 카톡 발송 = 임팩트 텍스트를 서버가 생성 → 복사 or 카톡 API. 색/서식 없이 기호만
· 링크 = 로컬 대시보드 라우트 /weekly-report?w=2026-W28 (주차 파라미터)
· 색 규칙 = status-color-semantics 준수 — 상태에 빨강/녹색 신호등 금지, 대기=보라
