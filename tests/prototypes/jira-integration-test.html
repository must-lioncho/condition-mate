STEP 3 · "유출되면?" 문제 — 어디에 저장하나

토큰 저장 위치 비교

비권장

.localdata / JSON 평문

  • 파일만 열면 그대로 노출 — git·백업·클라우드 동기화에 섞여 유출
  • 다른 프로세스도 홈 디렉터리 파일 읽기 가능
  • 실수로 커밋될 위험 상존
권장

macOS Keychain

  • OS가 암호화 저장 — 파일로 새어나가지 않음 (kSecClassGenericPassword)
  • 앱·사용자 단위 접근 제어, 잠금화면과 연동
  • Swift Security.framework로 바로 사용 (현재 코드베이스엔 미도입 → 신규)
원칙: 토큰은 Swift(앱) 쪽에서만 다루고 절대 웹뷰(JS)로 넘기지 않습니다. 대시보드는 "연결됨/끊김" 상태와 Jira에서 받아온 결과 데이터만 봅니다.
⚠ 이미 이 앱에 있는 안티패턴: Suno MCP 플러그인은 Bearer 토큰을 평문 .env에 저장하고 "401 뜨면 매시간 cURL로 토큰 수동 교체"합니다(Plugins/suno-mcp/README.md). — 이게 정확히 당신이 Jira에서 피하고 싶은 그 통증입니다. Jira는 이걸 반복하지 않습니다.
