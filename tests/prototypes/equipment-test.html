⚔️ 장비 + 숙련도 시스템 — 기획 + 인터랙션 테스트

장비는 장착으로 끝나지 않고 숙련도(EXP)가 함께 자랍니다. 전체 레벨 = 장비 숙련도의 평균이고, 평균이 7이 되면 Lv.7 완전자율입니다. 경험치는 포모도로(25분) 성공 시 지급되며, 그 세션에서 가장 많이 사용한 기술에 자동 부여됩니다.

기획 요약 (v2 — 숙련도 반영)
  • 장비 6종 = 네비 능력(대화·스킬·위임·워커·팀) + 플러그인. 각 장비에 숙련도 Lv.0(미장착) ~ Lv.7(마스터) + EXP 게이지.
  • 전체 레벨 = 6개 장비 숙련도의 평균(반올림, 최소 1). 예: 대화 6 + 스킬 4 + 나머지 0 → 평균 1.7 → Lv.2 (현재). 전 장비 마스터(평균 7) → Lv.7 완전자율.
  • EXP 지급 규칙: 포모도로 25분 성공 → +80 XP. 세션 동안의 사용 이벤트(스킬 실행, 대화 메시지, 에이전트 호출, 워커 실행, 플러그인 활동)를 집계해 최다 사용 기술 1곳에 전액 자동 부여. 사용 기록이 없으면 대화(기본기)에 부여. 실패/중단 시 지급 없음.
  • 시장 경험치 (레벨 밸런싱): 필요 EXP에 시장 인플레이션을 곱함. 한 달에 한 번 새 모델이 나온다고 보고 시장 레벨이 매월 +1, 그때마다 필요 EXP ×1.3 (누적 1.3^(시장Lv−1)). 300 XP 정도로 7레벨 도달이 가능하던 것을 시장이 성장할수록 어렵게 만들어, "지금의 완전자율"이 미래에는 평범해지는 것을 반영. 이미 획득한 레벨은 유지, 앞으로의 레벨업만 비싸짐.
  • 필요 EXP = (60 + 레벨×40) × 1.3^(시장Lv−1) → 고레벨 + 시장 성장 이중 브레이크. 곡선·배율은 튜닝 파라미터.
  • 8등신 아바타: 캐릭터는 사람 형태(머리=키의 1/8) 실루엣이고, 장비는 RPG처럼 부위에 착용 — 머리=대화, 무기=스킬, 방패=위임, 갑옷=플러그인, 어깨=팀, 신발=워커. 목걸이·반지 등 빈 부위가 남아 있어 아이템을 계속 늘릴 수 있음.
  • 실구현: 사용 이벤트는 이미 있는 로그(스킬 실행 기록, goal/API 호출, 워커 실행, 에이전트 ledger)에서 포모도로 시간창으로 집계. 숙련도 원장은 ~/.condition-manager/equipment.json, 조회는 /api/equipment.
  • 색 문법: 레벨 구간 시안(1–3)→레드(4–5)→퍼플(6–7) = 메뉴바 라이트닝 게이지 재사용. 진행/활성=블루 (신호등 녹·적 금지 규칙 준수).

이름은 대표 성장 경로일 뿐, 산정은 순서 무관(평균 기반). 한 장비만 몰아 올려도 평균이라 전체 레벨은 천천히 오름 — "골고루 다 써야 7"이라는 완전자율 취지와 일치. 실구현 시 평균·숙련도 계산은 서버가 하고 설정 칩과 장비창이 같은 /api/equipment 값을 공유.
