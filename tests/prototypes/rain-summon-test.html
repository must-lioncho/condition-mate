체크리스트

· 소환 성공 → 응답 즉시 캐릭터에 먹구름+빗줄기 페이드인, 발광이 폭풍우 블루로 전환
· 폭우 중 → 버튼 잠금 + "폭우 내리는 중 · 약 N분 남음" (폴링마다 갱신)
· XP 부족 → 소환 거부, 애니메이션 없음
· 종료(만료·강제) → 다음 폴링에서 페이드아웃, 메시지 클리어, 발광 원복
· ④ 외부 시작 → 소환 버튼 없이도 폴링만으로 애니메이션 켜짐 (앱 재시작·페이지 재진입 대응)

이벤트 로그

실제 연결 — 앱에서는 POST /api/equipment/rain 응답과 GET /api/equipment 15초 폴링에 실리는 rain:{active, remaining} 필드가 이 목 서버 역할을 합니다. 디렉터가 비활성이면 소환이 다음 틱으로 이월되므로(forcedRainPending) 애니메이션은 실제 빗소리가 시작되는 폴링 시점에 켜집니다.
