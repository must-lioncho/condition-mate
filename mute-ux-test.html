뮤트 UX 테스트 — 헤드폰 아이콘이 "들리는 중"을 말하게 하기

컨셉: 헤드폰 아이콘이 재생 중이면 이퀄라이저 애니메이션으로 "들리는 중"을 표현하고, 뮤트면 회색 + 사선이 그어지며 애니메이션이 멈춘다. (챌린지 다이얼의 녹색 비트 점과 같은 문법)
풀어야 할 문제: 현재 하단 스트립은 행 전체 클릭 = 설정 팝업이다. 아이콘에 뮤트 토글을 얹으면 "이 줄을 누르면 무슨 일이 생기는가"가 모호해진다. 아래 4개 시안을 직접 클릭해보고 어느 쪽이 헷갈리지 않는지 비교. 각 카드 하단 로그에 실제로 일어난 동작이 찍힌다.
추천: D안 (아이콘 = 뮤트 숏컷 + 메뉴 안에도 음소거 행 중복 제공)
  • 아이콘은 별도 히트영역(hover 시 배경+툴팁 "음소거")으로 분리 — hover 순간 "이건 버튼"임이 드러나 행 클릭(설정)과 시각적으로 구분된다.
  • 같은 기능을 설정 팝업 안 '음소거' 행에도 중복으로 둔다 — 아이콘을 버튼으로 인지 못한 사용자도 기존 경로(설정 열기)로 항상 도달 가능. 숏컷을 몰라도 손해가 없으므로 "혼동"이 실패로 이어지지 않는다.
  • 뮤트 시 서브텍스트에 "음소거됨"을 병기 — 사선+회색과 함께 상태를 텍스트로도 이중 표기.
  • 색 문법 준수: 들리는 중 = 녹색 비트(기존 cmch-mute와 동일), 뮤트 = 회색+흰 사선. 상태표시용 빨강/녹색 신호등은 쓰지 않음.
