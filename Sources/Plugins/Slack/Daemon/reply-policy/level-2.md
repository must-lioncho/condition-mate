# L2 — 스레드를 통으로 읽는다 (오늘의 기본값)

라우터가 L2 로 판정했을 때 여는 파일이다. 이 파일 하나로 행동이 끝난다.

**오늘 도는 것이 그대로 L2 다.** 이 레벨은 새로 만드는 것이 아니라 이름을 붙이는 것이고,
그래서 여섯 중 회귀 위험이 가장 낮다.

## 사양

| 축 | 값 |
|---|---|
| 무엇을 읽는가 | 스레드 전체. `conversations.replies` limit 30 → 뒤 12개, 2500자 클립. 스레드가 아니면 채널 직전 8개 |
| 모델 호출 | **1회** |
| 출력 | 1단계 번역 + 2단계 의미 1~3문장 + 3단계 의사결정 2개 |
| 토큰 대역 | 입력 **800~2500** (실측 중앙값 1302), 출력 **150~300** (실측 중앙값 201) |
| 딜리버리 | **2000~4000 ms** (실측 중앙값 2146, p90 3843) |
| 진입 조건 | **기본값.** 위아래 어느 규칙도 안 걸리면 L2 다 |
| 한계선 | 스레드 밖에 답이 있는 글은 여기서 못 푼다. 그때는 L3(회사 밖) 또는 L4(회사 안)다 |

## 기본값이라는 것의 뜻

판정이 서지 않으면 L2 다. 라우터가 L1 으로도 L3 으로도 확신하지 못했을 때 떨어지는 자리이고,
그것이 정상 동작이다. 확신 없이 위로 올리면 토큰과 지연이 늘고, 확신 없이 아래로 내리면
스레드에 이미 있는 답을 버린다.

**둘 중 더 비싼 실수는 아래로 내리는 쪽이다.** 2026-09-01 사고의 결론이 그것이었다 —
그 건의 정답은 L2 였고, 스레드 안에 이미 답이 있었는데 그것을 안 지켜서 틀렸다.
**더 깊이 파는 것이 답이 아니라 이미 손에 쥔 것을 안 버리는 것이 답이었다.**

## 이 레벨에서 남기는 이모지

레벨과 이모지는 다른 축이다. 라우터(`router.md` §1-4)가 이미 판정한 `decision` 값을 그대로
쓴다.

| `decision` | 언제 | 남기는 것 |
|---|---|---|
| `not-needed` | 어휘집이 실제로 물었다 (닫는 말, 또는 승인·동의·기원) | ✅ 또는 그 어휘가 지목한 이모지 |
| `needed` | veto 가 걸렸다 (묻는다·요청한다·막혀 있다·장애·길다) | **보는 중**(🔍) |
| `unknown` | 아무것도 안 잡힌 바닥값 | **보는 중**(🔍) |

L2 는 기본값이라 통과량이 가장 많고, 그래서 **잘못 단 이모지가 가장 많이 나가는 자리도
여기다.** 2026-09-02 사고의 항목도 L2 대역이었다. `decision === 'needed'` 인 항목은
리액션이 달려도 **미처리에 남는다**(`resolves: false`).

3단계 의사결정 2개가 나오는 레벨이라는 것이 이 판정과 겹쳐 읽힌다 — 의사결정을 뽑아 놓고
그 글에 ✅ 를 다는 것은 그 자체로 모순이다.

## 이 레벨이 하지 않는 것

- **공개 웹을 조회하지 않는다.** 젠스파크를 부르지 않는다. 그것은 L3 이다.
- **다른 채널·노션·지라를 조회하지 않는다.** 그것은 L4 다.
- **스레드를 30개 넘게 읽지 않는다.** limit 30 → 뒤 12개, 2500자 클립이 상한이다.
- **레벨을 근거로 출력 모양을 바꾸지 않는다.** 레벨은 `renderReply` 에 닿지 않는다
  (`docs/slack-ack-two-axis-design.md:290`).
