# L3 — 스레드 밖, 회사 밖 (공개 웹)

라우터가 L3 으로 판정했을 때 여는 파일이다. 이 파일 하나로 행동이 끝난다.

라이언 원문(2026-09-01): "레벨 3은 젠스파크로 외부에 있는 데이터를 가지고 검색해서 알 수
있는 정보가 레벨 3입니다. 이게 아주 간단한 건데, 외부 정보만으로 컨텍스트를 파악을 못 할
수가 있지."

## 사양

| 축 | 값 |
|---|---|
| 무엇을 읽는가 | L2 전부 + **공개 웹(genspark)**. `researchContext`(`answer-context.mjs:457`)가 `gsk search` 를 돈다 |
| 모델 호출 | 질의 생성 **1회**(가장 싼 모델) + 본 분석 **1회** |
| 출력 | L1·L2 카드 + **L3 카드** — 외부가 더한 것 + 출처 URL 한 줄 |
| 토큰 대역 | 입력 **2500~6000**, 출력 **250~400** |
| 딜리버리 | 근거 레이어 **≤ 20초**(`ACK_LAYER_BUDGET_MS`) + 모델 **≤ 15초** |
| 진입 조건 | `APPROACH = 외부 조사` |
| 한계선 | **밖을 다 뒤져도 맥락이 안 잡히는 것이 있다.** 그것이 L4 로 넘어가는 이유다(라이언) |

## 진입은 정규식이 아니라 `APPROACH` 가 정한다

`problem-frame.mjs` 가 내는 닫힌 집합에서 `외부 조사` 가 나왔을 때만 이 레벨이다. 물음
신호를 정규식으로 잡아 여기로 올리지 않는다 — 판정기를 새로 만들면 이미 도는 판정기와
갈라진다.

## 실측이 보인 것 두 가지 — 이 레벨을 쓸 때 같이 본다

**첫째, 공개 웹에 원리적으로 답이 없는 물음이 여기로 올라온 적이 있다.** 디스크에 남은
유일한 실호출에서 일정 확정 요청이
`hire freelance English interpreter for online business meeting` 이라는 영어 질의가 되어
Upwork·Freelancer 링크를 물어 왔다. 결과는 빵점이었다. 사내 일정은 공개 웹에 없다.

**둘째, 리서치는 판정으로 도는 것이 아니라 사실상 무조건 돈다.** 켜고 끄는 유일한 값이
`slack-permission-policy.json` 의 `"research": 1` 이고 `defaultLevel: 2` 이므로
`2 >= 1` 이 언제나 참이다. **모든 작성자, 모든 메시지에 켜져 있다.**

그래서 이 레벨을 고를 때 물어야 할 것은 "외부에 있을 법한가"가 아니라 **"이 물음의 답이
공개 웹에 있을 수 있는가"** 다. 사내 일정·사내 승인·사람의 의사는 아무리 검색해도 없다.

## 이 레벨에서 남기는 이모지

레벨과 이모지는 다른 축이다. 라우터(`router.md` §1-4)가 이미 판정한 `decision` 값을 그대로
쓴다.

| `decision` | 언제 | 남기는 것 |
|---|---|---|
| `not-needed` | 어휘집이 실제로 물었다 (닫는 말, 또는 승인·동의·기원) | ✅ 또는 그 어휘가 지목한 이모지 |
| `needed` | veto 가 걸렸다 (묻는다·요청한다·막혀 있다·장애·길다) | **보는 중**(🔍) |
| `unknown` | 아무것도 안 잡힌 바닥값 | **보는 중**(🔍) |

L3 까지 올라온 글은 외부 조사가 필요하다고 판정된 것이므로 `decision` 이
`not-needed` 로 나오는 경우가 드물다. 드문 것과 없는 것은 다르므로 판정은 그대로 따른다.
`decision === 'needed'` 인 항목은 리액션이 달려도 **미처리에 남는다**(`resolves: false`).

**근거 레이어가 20초를 다 쓰고 빈손으로 끝나도 그것이 ✅ 의 근거가 되지 않는다.**
2026-09-02 사고의 항목이 정확히 그 경로였다 — `NO_BASIS` 로 강등되면서 ✅ 가 나갔다.
근거를 못 찾은 것은 의사결정이 필요 없다는 뜻이 아니다.

## 이 레벨이 하지 않는 것

- **다른 채널·노션·지라를 조회하지 않는다.** 그것은 L4 다. L3 은 회사 밖만 본다.
- **출처 없이 외부 사실을 쓰지 않는다.** L3 카드에는 출처 URL 한 줄이 붙는다.
- **웹 리서치 결과를 스레드에 올라가는 노트에 싣지 않는다.**
- **근거 레이어 20초를 넘겨 기다리지 않는다.** `ACK_LAYER_BUDGET_MS` 하나로 통째로
  마감한다.
