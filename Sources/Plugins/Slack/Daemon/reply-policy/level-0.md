# L0 — 읽지 않는다

라우터가 L0 으로 판정했을 때 여는 파일이다. 이 파일 하나로 행동이 끝난다.

이 레벨은 새로 만든 것이 아니라 이미 도는 경로에 이름을 붙인 것이다
(`slack-eyes-daemon.mjs:1991`, `:2001`).

## 사양

| 축 | 값 |
|---|---|
| 무엇을 읽는가 | 메시지 본문 한 덩어리. **슬랙 API 호출 0회.** |
| 모델 호출 | **0회** |
| 출력 | 의미 분석 **없음**. `meaning` 필드를 만들지 않는다. 리액션 하나. |
| 토큰 대역 | **0** |
| 딜리버리 | **< 50 ms** (정규식만 돈다) |
| 진입 조건 | `APPROACH = 응답 불필요`, 또는 `emoji-layer.mjs` 의 `responseGrade()` 가 `R1` 이고 어휘집 `level0` 항목이 물었을 때 |
| 한계선 | 없다. 이 레벨은 아무것도 조회하지 않으므로 실패할 자리가 없다 |

## 무엇을 하는가

1. 본문을 정규화한다(`normalizeText`). 멘션·링크·`Cc:` 줄·`:emoji:` 코드를 걷어낸다.
2. 어휘집(`slack-emoji-layer.json`)의 `level0` 항목과 맞춰 본다.
3. 물린 항목의 이모지 하나를 단다. 끝이다.

번역도 의미 분석도 만들지 않는다. 만들면 이 레벨의 토큰 대역 0 이 깨진다.

**판정은 번역 앞에 온다.** 지금 구조에서 이 판정이 번역이 끝난 뒤에 나오면 토큰을 이미 다
쓴 뒤이고, 그러면 이 레벨이 존재하는 이유가 없어진다.

## 이 레벨에서 남기는 이모지

L0 의 진입 조건 자체가 **닫는 말이 어휘집에 물린 것**이다. 그래서 이 레벨의 `decision` 은
언제나 `not-needed` 다.

| `decision` | 남기는 것 |
|---|---|
| `not-needed` | 어휘집이 지목한 이모지 하나 — 오늘은 ✅(확인만 함) 하나다 |

**L0 에서 보는 중 이모지가 나가는 일은 없다.** 나갔다면 그것은 L0 판정이 틀린 것이다 —
어휘집이 물지 않았는데 L0 으로 떨어졌다는 뜻이므로, 이모지를 바꿀 것이 아니라 진입 조건을
본다.

✅ 의 뜻은 어휘집에 적힌 것이 정본이다 — **"체크는 했다"이지 동의도 승인도 아니다.**
그런데 받는 쪽은 그렇게 안 읽는다는 것이 2026-09-02 사고가 보인 것이므로, ✅ 는 상대가
**이미 닫은 말**에만 단다. 그것이 L0 의 진입 조건이 좁은 이유다.

이 레벨의 항목은 리액션 하나로 해결된 것이 맞으므로 처리완료로 넘어간다
(`resolves: true`).

## 이 레벨이 하지 않는 것

- **스레드를 부르지 않는다.** `conversations.replies` 도 `conversations.history` 도
  호출하지 않는다.
- **모델을 부르지 않는다.** 0회다.
- **`meaning` 을 만들지 않는다.** 컨텍스트 탭에는 "이모지 하나로 끝난 메시지입니다 —
  의미 분석을 만들지 않았습니다" 가 뜬다. 이것은 실패가 아니라 설계다. "컨텍스트 수집에
  실패했습니다" 로 표시하면 안 된다.
- **글을 만들지 않는다.** 글이 필요하다고 판단되면 그것은 L0 이 아니다.
