# L1 — 단문만 읽는다

라우터가 L1 으로 판정했을 때 여는 파일이다. 이 파일 하나로 행동이 끝난다.

라이언 구술 그대로다 — "현재 단문 하나만 본다."

## 사양

| 축 | 값 |
|---|---|
| 무엇을 읽는가 | **현재 메시지 본문만.** 스레드를 안 부른다. **슬랙 API 호출 0회.** |
| 모델 호출 | **1회** |
| 출력 | 1단계 번역 + 2단계 의미 **한 줄**(최대 60자). **3단계 의사결정 없음.** |
| 토큰 대역 | 입력 **≤ 400**, 출력 **≤ 80** |
| 딜리버리 | 목표 **≤ 1200 ms** (스레드 fetch 왕복 1회가 통째로 빠진다) |
| 진입 조건 | `APPROACH = 컨텍스트 확인` 이고, 스레드를 안 봐도 뜻이 서는 단문일 때 |
| 한계선 | 스레드에 답이 있는 글은 여기서 못 푼다. 그때는 L2 다 |

## 무엇을 하는가

모델을 한 번 부른다. 프롬프트는 `translatePrompt` 에서 두 가지를 뺀 것이다.

- **3단계 블록(218자)을 뺀다.** 의사결정을 만들지 않는다.
- **2단계의 컨텍스트 지시를 뺀다.**

`<context>` 태그 자체를 넣지 않는다. **빈 태그를 넣으면 모델이 "컨텍스트 부족"을 쓴다.**
없는 것과 비어 있는 것은 다르고, 모델에게는 후자가 결함 신호로 읽힌다.

## L0·L2 와 무엇이 다른가

| 견주는 대상 | 차이 |
|---|---|
| L0 | **글이 한 줄 나가느냐.** L0 은 리액션뿐이고 L1 은 번역과 의미 한 줄이 있다 |
| L2 | **스레드를 부르느냐.** L1 은 안 부르고 L2 는 부른다 |

## 이 레벨에서 남기는 이모지

레벨과 이모지는 다른 축이다. 라우터(`router.md` §1-4)가 이미 판정한 `decision` 값을 그대로
쓴다. 레벨이 L1 이라는 사실만으로 이모지가 정해지지 않는다.

| `decision` | 언제 | 남기는 것 |
|---|---|---|
| `not-needed` | 어휘집이 실제로 물었다 (닫는 말, 또는 승인·동의) | 닫는 말이 지목한 이모지(오늘은 ✅ 하나). 무거운 어휘(👌·👍)는 승인 뜻이라 ✅ 로 접힌다 |
| `needed` | veto 가 걸렸다 (묻는다·요청한다·막혀 있다·장애·길다) | **보는 중**(🔍) |
| `unknown` | 아무것도 안 잡힌 바닥값 | **보는 중**(🔍) |

이 레벨에서 자동으로 나갈 수 있는 이모지는 **✅ · 🔍 둘뿐이다.**

🫡 는 2026-09-02 라이언 확정으로 **이 축을 떠났다.** 뜻이 "존중" 에서 **"이 글은 라이언이
아니라 라이언의 에이전트가 대신 썼다"** 는 발신자 표시로 바뀌었기 때문이다. 들어온 글에 다는
리액션이 아니라 나간 글에 다는 표시이므로 이 어휘집이 다룰 것이 아니다. 규칙 본문은 공용
레이어 `~/.must-aios/sources/docs/slack-layers/layer-2-attribution.md` 에 있고, 그 문서가 **"이 값을 본문에서
추론하지 않는다 — 발신하는 쪽은 자기가 그 글을 썼는지 아닌지를 이미 안다"** 를 못박았다.
어휘집은 본문에서 추론하는 자리이므로 자격이 없다.

**이 사유는 아래 🙏·🙇 와 다르다.** 저 둘은 정밀도 미달이라 껐고 🫡 는 뜻이 바뀌어 껐다.
그래서 🫡 는 정밀도가 아무리 올라도 되살리면 안 된다 — 되살리면 한 이모지에 뜻이 둘 얹히고,
9/2 에 동료가 ✅ 를 두고 채널에서 "그건 자동 승인이 아니다" 를 대신 설명해야 했던 일이
🫡 로 반복된다.

🙏 기원과 🙇 겸손은 뜻이
어휘집에 정본으로 남아 있지만 **자동으로는 달지 않는다** — 3개월 코퍼스(clean 3,174건) 실측
정밀도가 0.00(표본 2) 과 0.07(표본 14) 로 채택선 0.70 · 표본 8 에 못 미쳤다(2026-09-02).
접힘 해제 경로 자체는 살아 있고 그 자리에 오늘 주인이 없을 뿐이다 — `router.md` §1-4 와
SPEC SLKST-11 이 같은 말을 한다.

`decision` 이 무엇이든 **이 레벨이 다는 리액션은 항목을 닫지 않는다** — 어휘집의 `resolvesPolicy` 는 2026-09-06 부터 `self` 이고, 라이언 본인이 슬랙에서 직접 단 리액션만 항목을 닫되 그중에서도 이 시스템이 그 항목에 단 이모지(`ackEmoji`·`ackEmojis`)는 뺀다. 여기서 나가는 ✅·🫡·🔍 가 바로 그 제외 대상이라, 달아 놓고 스스로 그 항목을 지우는 일은 일어나지 않는다. 남이 단 리액션도 여전히 닫지 못한다(`router.md` §1-6).
L1 은 짧은 글이라 의사결정과 무관해 보이기 쉬운데, 짧다는 것과 의사결정이 필요 없다는 것은
다른 상태다. **모르면 ✅ 가 아니라 보는 중이다.**

## 이 레벨이 하지 않는 것

- **스레드를 부르지 않는다.** 슬랙 API 호출이 0회라는 것이 이 레벨의 정의다. 한 번이라도
  부르면 딜리버리 1200 ms 가 깨지고, 그러면 L2 와 구분되지 않는다.
- **3단계 의사결정을 만들지 않는다.** 단문 하나로 의사결정 두 개를 뽑으면 근거 없는
  문장이 나온다.
- **의미를 60자 넘게 쓰지 않는다.**
- **공개 웹을 조회하지 않는다.** 그것은 L3 이다.
