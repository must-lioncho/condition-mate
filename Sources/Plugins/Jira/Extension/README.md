# 지라 번역 크롬 익스텐션 (로컬 전용)

지라 화면의 영어 텍스트 오른쪽에 번역 버튼을 띄우고, 누르면 한국어를 원문 옆(또는 아래)에 붙인다.
크롬 웹스토어에 올리지 않는다 — 이 컴퓨터에 압축해제 확장으로만 설치한다.

## 왜 앱을 거치는가

익스텐션은 Gemini API 키를 모른다. 키를 브라우저에 두면 그 프로필을 읽을 수 있는 무엇이든
키를 가져갈 수 있어서다. 대신 앱이 `127.0.0.1:17321`에 번역 전용 브리지를 열고, 키는
키체인(`cm-gemini-api-key`, 슬랙 번역과 같은 키)에만 둔다.

    지라 페이지 ─ content.js ─ background.js ─(토큰)─ 앱 브리지 ─(키체인 키)─ Gemini Flash-Lite

브리지가 지키는 선:

- `127.0.0.1` 에만 바인딩 (LAN에서 보이지 않는다)
- 공유 토큰 필수 — 토큰은 `~/.condition-mate/jira-bridge/token`(0600)
- `Origin` 이 있으면 `chrome-extension://` 이어야 한다 (웹페이지의 fetch는 403)
- CORS 허용 출처는 그 익스텐션 하나뿐 — `*` 를 쓰지 않는다
- 본문 512KB · 한 번에 60조각 · 분당 40회 상한

## 설치

    Scripts/install-jira-ext.sh

토큰을 심어 `~/.condition-mate/chrome-jira-translate` 로 복사한다. 그 다음 크롬에서 한 번만:

1. `chrome://extensions`
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 위 폴더 선택

소스를 고친 뒤에는 스크립트를 다시 실행하고 확장 카드의 새로고침을 누른다.

## 쓰는 법

지라에서 번역하고 싶은 곳에 마우스를 올리면 그 오른쪽에 파란 **번역** 버튼이 뜬다.

| 대상 | 결과 위치 |
| --- | --- |
| 이슈 제목 · 설명 · 댓글 | 원문 바로 아래 블록 |
| 백로그 · 타임라인 행, 보드 카드 | 행 옆에 뜨는 패널 (행 높이가 고정이라 아래에 넣으면 잘린다) |

이미 한국어인 텍스트는 호출 없이 "이미 한국어입니다"로 끝난다. 같은 문장은 앱이 캐시하므로
두 번째부터는 즉시 나온다.

## 끄기

시스템 관리 화면의 워커 목록에서 **지라 번역** 을 끄면 포트가 바로 닫힌다
(`~/.condition-mate/jira-bridge-disabled`).

## 파일

| 파일 | 역할 |
| --- | --- |
| `manifest.json` | MV3 선언. host_permissions는 브리지 주소 하나뿐 |
| `config.js` | 브리지 주소·토큰. 레포 원본의 토큰은 항상 비어 있다 (설치 스크립트가 채운다) |
| `background.js` | 브리지 호출 전담 서비스 워커. 토큰은 여기서만 다룬다 |
| `content.js` | 번역 대상 판별, 떠다니는 버튼, 결과 표시 |
| `content.css` | 지라의 라이트·다크 테마 위에 얹히는 스타일 |
| `options.html/js` | 언어 선택, 토큰 수동 입력, 연결 확인 |

## 지라 화면이 바뀌어 버튼이 안 뜰 때

`content.js` 맨 위의 `SEL` 만 고치면 된다. 되도록 바뀌지 않는 것에 걸어 두었다 —
ADF 렌더러 클래스(`.ak-renderer-document`)와 `/browse/<이슈키>` 링크. `data-testid` 는
지라 릴리스마다 바뀌므로 보조 수단으로만 쓴다.
