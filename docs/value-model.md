# 토큰 뷰 투입 지수 / 성과 모델

토큰 뷰의 두 모드 중 **투입 지수** 모드가 쓰는 점수 계산법과, 아직 못 재는 **성과(가치)** 의 관계.

> **핵심 원칙: 투입(비용)과 성과(가치)를 한 숫자로 합치지 않는다.**
> 토큰·시간은 *얼마나 썼나*(투입)일 뿐 *얼마나 벌었나*(성과)가 아니다. 이걸 $나 "가치"로
> 표기하면, 돈만 쓰고 성과 없는 것을 성과로 포장하는 지표(마케팅 회사가 100억 쓰고 매출
> 기여 0인데 성과로 인정해달라는 격)가 된다. 그래서 무단위 **투입 지수(pt)** 로만 표기하고,
> 성과·ROI 슬롯은 비워서 상시 노출한다.

## 3층 구조

| 층 | 내용 | 지금 측정? | 표기 |
|---|---|---|---|
| **투입 (비용)** | 토큰, 시간 | O | 투입 지수(pt) |
| **활동량 (산출물 수)** | 완료 목표·세션 수 | O (단, 가치 아님) | 세션 N 배지 |
| **성과 (가치)** | 회사 goal 임팩트 | X (미측정) | 🔒 잠금 |

진짜 지표 = **ROI = 성과 ÷ 투입**. 성과가 없으면 계산 불가 → 억지로 채우지 않고 비워 둔다.

## 두 가지 표시 모드 (탭)

- **토큰량** (기본): 세션이 실제로 쓴 토큰(K). 원시 투입.
- **투입 지수**: 아래 모델로 토큰을 무단위 지수(pt)로 환산 + 시간효율 반영. **성과 아님, 투입 측 지표.**

## [2] 토큰효율 (투입 지수의 기본)

100% 한 달 토큰량을 **600,000 K (=600M, 캐시 생성 포함)** 로 가정. 100% 한 달 = **10,000 pt**.

```
W = IDX_PER_MONTH / FULL_MONTH_K = 10000 / 600000 ≈ 0.0167  (pt/K)
투입지수 = tokens_K × W
```

- 1,000 K(1M 토큰) ≈ 16.7 pt, 피크일 20,000 K ≈ 333 pt, 풀 한 달 = 10,000 pt.
- 튜닝: 실제 100% 사용량이 다르면 `FULL_MONTH_K`만 바꾼다.

## [3] 시간효율 배수 (F)

같은 투입 지수를 **더 적은 시간**에 굴렸으면 도구를 더 효율적으로 쓴 것(노동생산성, 여전히 투입 측). 성과가 아니라 "적은 사람 시간에 같은 양의 AI 작업"을 뜻한다.

```
FULL_MONTH_H = 720   (30일 × 24시간)
BASE_RATE    = IDX_PER_MONTH / FULL_MONTH_H = 10000 / 720 ≈ 13.9  (pt/시간)
F            = (투입지수 / 활성시간) / BASE_RATE
시간보정 투입 = 투입지수 × F
```

### 예시

| | 투입 pt | 시간 | pt/시간 | F | 시간보정 |
|---|---|---|---|---|---|
| A | 10,000 | 720h | 13.9 | ×1.00 | 10,000 |
| B | 10,000 | 200h | 50.0 | ×3.60 | 36,000 |

→ 같은 10,000 pt를 B는 200h에 굴렸으니 도구 활용이 더 효율적. (단, 이것도 **투입 효율**이지 성과가 아님 — 성과가 실제로 컸는지는 [5] 필요.)

## [4] 활동량 (세션 폭)

부모 goal 하나에 매달린 **세션(자식) 수 = 산출물의 폭**. 1세션=1, 100세션=100. 투입 지수 모드에서 부모 행에 `세션 N` 배지로 표시. **가치가 아니라 활동량**이며, 토큰효율과 곱해 중복 계산하지 않는다.

## [5] 성과(가치) / ROI (COMING SOON — 미구현)

회사 goal 개념이 없어 **실제 성과 가치**를 못 구한다. 같은 "200시간·1600세션·부모 10개 완료"라도 실가치는 $500일 수도 $50,000일 수도 있는데, 이를 가르려면 각 부모 목표를 **회사 goal(사업적 임팩트)** 에 연결해야 한다.

```
성과가치(parent)  = 그 목표가 진척시킨 회사 goal의 임팩트 배분
ROI              = Σ 성과가치 / Σ 투입(원가 or 투입지수)
성과/시간         = Σ 성과가치 / 활성시간
```

### 예시 (구분 불가 문제)

- X: 200h, 세션 1600개, 부모 10개 완료 → 연결 goal이 사소하면 성과 $500
- Y: 같은 규모라도 핵심 매출 goal을 끝냈으면 성과 $50,000

투입(토큰·시간·세션 수)만으로는 X·Y를 구분 못 한다. **회사 goal 정의 + 목표-goal 링크**가 선행돼야 하며, 그전까지 화면은 "얼마 **썼나**(투입)"만 보여주고 "얼마 **벌었나**(성과)"는 🔒로 비워 둔다.
