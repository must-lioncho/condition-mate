이 화면이 실제로 하는 일 (판단용 메모)

  • 1계정 슬롯 = 크리덴셜 스냅샷. "계정 추가"는 현재 로그인된 ~/.claude/.credentials.json(+ Keychain OAuth 토큰)을 이름 붙여 저장합니다. "활성화"는 저장된 슬롯을 다시 ~/.claude로 스왑 — teamclude와 동일한 방식입니다.
  • 2계정별 독립 한도. 각 계정은 자기만의 5시간/주간 한도를 가집니다. 사용량은 그 계정으로 실행된 세션의 토큰을 트랜스크립트에서 합산해 추정합니다.
  • 3Codex 폴백은 "제안 → 수동 확정". 활성 계정이 임계값을 넘으면 배너로 제안만 하고, 실제 전환은 버튼을 눌러야 일어납니다. 자동으로 몰래 바꾸지 않습니다.
  • 4엔진 전환 = 워커 라우팅 변경. 헤드리스 워커(claude -p)를 codex exec로 바꿔 실행합니다. Codex CLI는 현재 미설치 상태라, 승인하시면 설치/연동을 다음 단계에서 진행합니다.
