# 답변 AI 실행 정보 — 내부 표시

사용자의 최종 정정: Slack 답변과 MD 첨부는 현재 그대로 둔다. 모델, effort, 컨텍스트 윈도우, 토큰 사용량은 Condition Mate 내부에서 분리해 표시한다.

- 실제 답변 생성 호출 및 언어 재시도의 모델 응답 메타데이터를 수집한다.
- 답변이 성공적으로 게시된 항목에만 ackAI를 저장한다. 프롬프트나 비밀키는 저장하지 않는다.
- 모델 ID, 요청 모델, 실행 경로, 앱 effort 설정, 입력 한도와 실사용 입력, 출력·추론·캐시·전체 토큰을 구분한다.
- 값이 제공되지 않았으면 미제공/미기록으로 표시한다. 과거 번역 모델을 답변 모델로 추정해 채우지 않는다.
- 모델 한도는 공식 Models API의 실제 값만 사용한다. Slack 본문과 MD 렌더러에는 메타데이터를 넘기지 않는다.
- 격리된 모의 응답으로 동시 처리, 재시도, 메타데이터 조회 실패, 발신/미발신 UI, 외부 MD 불변을 검증한다. 검증 메시지를 Slack에 발송하지 않는다.

참조: https://ai.google.dev/api/models , https://platform.claude.com/docs/en/api/http/models/retrieve
