# 루프 활동 누락 해결 지시문

## 확인한 문제
- 세션 원장은 ~/.claude/projects 최상위 JSONL만 수집한다. Slack 직접 Gemini 호출은 actions-daemon.jsonl에만 남는다.
- run.day에 마지막 토큰 사용일을 넣어 여러 날 활동한 세션이 이전 날짜에서 빠진다.
- 최근 24시간 수정 파일만 탐색하면 앱 미실행 중 생긴 오래된 기록이 누락된다.
- 분석 완료 표시는 모든 실행 경로의 완전성을 보장하지 않는다.

## 실행
1. Slack model.usage 기록 중 직접 API 호출을 같은 루프에 합친다. 세션 수와 API 호출 수는 별도 표시한다.
2. 신규 로그에 실행 경로를 명시한다. 과거 Gemini 기록은 API로 확정할 수 있다. 과거 경로 미기록 Claude 호출은 세션과 중복 가능하므로 합산하지 않고 한계를 표시한다.
3. 각 세션에 일별 사용량을 제공하고, 기간 내 활동일이 있으면 포함한다. 기간별 토큰·비용도 일별 합으로 맞춘다.
4. 파일 전체의 지문을 탐색하되 변경 파일만 파싱한다. 주기 조회로 수집 진행을 갱신한다.
5. 완료 문구는 Claude 파일 분석 범위를 명시하고 API 집계 범위·한계를 함께 보여준다.
6. 기존 작업 변경을 보존한다. 외부 Slack 메시지를 발송하지 않는다.

## 검증
- 9월 18일 Gemini 호출이 실제 로그와 집계에서 일치한다.
- 여러 날 활동한 세션은 각 날짜에서 해당 날짜 토큰만 표시한다.
- CLI usage 행은 중복 합산하지 않는다. 경로 미기록 Claude는 별도로 표시한다.
- 회귀 테스트 및 앱 빌드 성공. 결과와 적용 상태를 result.md에 기록한다.
